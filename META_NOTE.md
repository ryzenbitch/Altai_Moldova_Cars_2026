# Примечание по .meta файлам

Unity автоматически создаёт .meta файлы при добавлении скриптов в проект.
Тебе не нужно их создавать вручную — просто скопируй .cs файлы в папку Scripts в Unity,
и IDE сгенерирует .meta файлы сам при следующей компиляции.

## Порядок копирования файлов:

1. Открой свой Unity проект
2. В папке Assets создай структуру папок как в SETUP_GUIDE.md
3. Скопируй все .cs файлы в соответствующие папки
4. Скопируй 7.png–13.png в Assets/Resources/Cards/
5. Unity автоматически скомпилирует скрипты

## Если видишь ошибки компиляции:

- Убедись что TextMeshPro импортирован (Window → TextMeshPro → Import TMP Essential Resources)
- Проверь что все файлы скопированы (не только часть из них)
- Ошибки типа "The type or namespace 'TMPro' could not be found" = нужно импортировать TMP
